# 수정체탈구.com — 예스안과의원 랜딩 사이트

## 구성
- HTML 6페이지: 홈 / 인공수정체 탈구 / 다초점 인공수정체 탈구 / 수정체 탈구 / 수술 방법 / FAQ
- assets/style.css, assets/iol-illustration.svg, assets/og-image.svg
- robots.txt, sitemap.xml

## 배포
1. ZIP을 풀고 안의 파일들을 정적 웹 호스팅(Cloudflare Pages, Netlify, 일반 웹호스팅 등)의 공개 루트에 업로드합니다. ZIP 자체를 그대로 열어 웹사이트로 사용하지는 않습니다.
2. 도메인 **수정체탈구.com**을 호스팅에 연결하고 HTTPS를 활성화합니다. `www` 주소를 사용하는 경우 기본 도메인으로 301 리디렉션합니다.
3. 이 HTML은 `/assets/...`처럼 루트 경로를 쓰므로 로컬 파일 더블클릭보다 웹서버에서 미리 보는 것이 정확합니다. 예: `python -m http.server 8000` 실행 후 `http://localhost:8000/`.
4. 네이버 서치어드바이저와 구글 서치콘솔에서 도메인 소유권 확인 후 `https://수정체탈구.com/sitemap.xml`을 제출합니다.
5. **예스안과 공식 병원 이미지 및 학술 논문 이미지**는 사용 권한을 확인한 뒤 저장한 실제 파일로 교체합니다. 본 초안의 시각 자료는 자체 제작 SVG 도식으로 대체했습니다.
6. 기존 예스안과 홈페이지 및 블로그에서 관련 설명 글과 링크를 새 사이트의 각 상세 페이지에 연결하세요. 서로 다른 사이트에 동일한 글 전체를 중복 게시하지 마세요.
7. 의료진의 실제 담당 범위, 수술방법 표현, 허가·심의 필요 사항, 전화번호·진료시간을 최종 검수하세요. 환자 사진·사례는 별도 동의 및 비식별 처리 후 게시하세요.

## SEO 기술사항
- 각 페이지의 독립 제목/설명/H1, canonical, Open Graph, 의미 있는 내부링크
- 본문 HTML 직접 노출 (JS 없이 크롤링 가능)
- MedicalClinic/WebPage 및 일부 FAQ의 JSON-LD 구조화 데이터
- robots.txt / sitemap.xml
- Google / Naver / AI 검색 서비스의 1위 노출은 보장할 수 없습니다. 검색 색인은 실제 배포 이후 확인 가능합니다.
